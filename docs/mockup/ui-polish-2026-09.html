Switch windows in one screen, on a phone and on a desk

The switcher spends about 95 px per window: a two-line card plus an always-present "add note" row. Eleven windows in one repo take three phone screens. This mock keeps every fact the row carries today, drops the ones that never change a decision, and gives desktop a foldable panel instead of a phone-width modal. Callout numbers on each frame map to the list beside it. Proposals are tagged proposed when they are in scope for this pass and later when they are only sketched.

6 · What stays the same

Boundaries of this change

AreaStatus
tmux as source of truthUnchanged. Notes still live on the window option @tm_annotation; the tree is built from metadata the connector already sends.
Connector and protocolNo change, no version bump. Everything here is public/app.js, public/styles.css, public/index.html, plus one pure filter helper with a node test.
Phone layoutBottom sheet stays. It gets the dense rows, the filter, and the "Needs you" group; no bottom tab bar, per the product notes.
GroupingRepo → directory → windows from the August change stays as is, including the branch chip only when it differs from the directory name.
Status vocabularyUnread dot, agent chip glyphs (● ✓ ❓ ?), live badge, and their colors are reused, not redrawn.
Recents popup and needs-you pillKept in the topbar. On desktop the popup and the sidebar can be open at the same time.
7 · Decisions to make

Reply with the ones to change

Defaults are what the frames show. Anything unticked is built as drawn.

  • Dim the repeated repo/dir prefix in window names (drawn) versus strip it entirely versus leave names untouched.
  • Pin a "Needs you" group at the top of the tree (drawn) versus rely only on the topbar pill.
  • Sidebar footer with New window, Duplicate, Transcript (drawn) versus no footer.
  • Desktop breakpoint at 900 px (drawn) versus wider, for example 1100 px, so tablets in landscape keep the sheet.
  • Fold the phone toolbar into the topbar and move Refresh and Auto to the More menu (section 5) versus leave the phone toolbar alone.
  • Shortcuts: ⌘K filter, ⌘B fold, ⌥↑/↓ prev/next (drawn). Add [ and ] as single-key prev/next on desktop, or keep everything behind a modifier.
  • Fleet icon in the app topbar (section 5) versus keep it in the More menu only.
